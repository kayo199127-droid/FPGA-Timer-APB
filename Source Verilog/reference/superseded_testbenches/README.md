# Superseded Testbench Drafts

The SystemVerilog files in this folder are retained only for traceability. They target an earlier, incompatible module interface and are not part of the canonical verification suite.

Use the three current testbenches in `../../tb/`: `tb_register.v`, `tb_timer_divider.v`, and `tb_timer_top.v`. The simulation scripts compile only these canonical testbenches.
